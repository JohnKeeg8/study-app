# IPv4 addressing

An IPv4 address is **32 bits**, written as four **octets** (8 bits each) in decimal, e.g. **192.168.10.25**. Each octet ranges from 0 to 255. Every address has two parts:

- **Network portion:** which network the host is on (all hosts on a subnet share it).
- **Host portion:** which device on that network.

The **subnet mask** (e.g. 255.255.255.0) or **CIDR prefix** (e.g. /24) says how many bits are network bits.

## Masks and CIDR notation

A mask is a run of **1 bits (network)** followed by **0 bits (host)**. The prefix length counts the 1s:

| Prefix | Mask | Host bits | Usable hosts |
|---|---|---|---|
| /8 | 255.0.0.0 | 24 | 16,777,214 |
| /16 | 255.255.0.0 | 16 | 65,534 |
| /24 | 255.255.255.0 | 8 | 254 |
| /25 | 255.255.255.128 | 7 | 126 |
| /26 | 255.255.255.192 | 6 | 62 |
| /27 | 255.255.255.224 | 5 | 30 |
| /28 | 255.255.255.240 | 4 | 14 |
| /29 | 255.255.255.248 | 3 | 6 |
| /30 | 255.255.255.252 | 2 | 2 |

Memorize the mask octet values for 1–8 bits: **128, 192, 224, 240, 248, 252, 254, 255**.

## Address classes

The original **classful** system divides addresses by the **first octet**:

| Class | First octet | Leading bits | Default mask | Used for |
|---|---|---|---|---|
| **A** | 1–126 | 0 | 255.0.0.0 (/8) | Unicast, very large networks |
| **B** | 128–191 | 10 | 255.255.0.0 (/16) | Unicast, medium networks |
| **C** | 192–223 | 110 | 255.255.255.0 (/24) | Unicast, small networks |
| **D** | 224–239 | 1110 | none | **Multicast** |
| **E** | 240–255 | 1111 | none | **Experimental** |

- 127 is reserved for loopback, so Class A is usually listed as 1–126.
- Today networks use **CIDR**, not classes. Classes still matter for exam questions about ranges and default masks.

## Public, private, and special addresses

**Private (RFC 1918) ranges** aren't routed on the internet. Hosts using them need **NAT/PAT** at the edge to get online:
- **10.0.0.0/8:** 10.0.0.0 – 10.255.255.255 (Class A)
- **172.16.0.0/12:** 172.16.0.0 – **172.31**.255.255 (Class B)
- **192.168.0.0/16:** 192.168.0.0 – 192.168.255.255 (Class C)

Everything else in Classes A–C is **public** (internet-routable). Watch the edges: **172.15.x.x** and **172.32.x.x** are public, and so is **192.169.x.x**.

**Special addresses:**
- **Loopback, 127.0.0.0/8** (usually 127.0.0.1): tests the local TCP/IP stack; never leaves the host.
- **APIPA (link-local), 169.254.0.0/16:** Windows **assigns itself** one of these when it **can't reach a DHCP server**. It only works on the local link, so seeing 169.254.x.x is a classic DHCP-failure clue.
- **0.0.0.0:** "no address yet" (the source of a DHCP Discover). **0.0.0.0/0** means the **default route**.
- **255.255.255.255:** limited broadcast to the local network.

## Subnetting step by step

**Subnetting** splits one network into smaller ones by **borrowing host bits** for network bits. These formulas cover most questions:

- **Usable hosts per subnet = 2^h − 2**, where h = host bits. Subtract 2 because the **network ID** (first address) and **broadcast** (last address) can't be assigned to hosts.
- **Number of subnets = 2^b**, where b = borrowed bits.
- **Block size = 256 − the mask value in the interesting octet** (the last octet with network bits). Subnets start at multiples of the block size.

**Worked example: 192.168.10.77/26**
1. **Mask:** /26 = 255.255.255.**192**. The interesting octet is the 4th.
2. **Block size:** 256 − 192 = **64**. Subnets start at .0, .64, .128, .192.
3. **Find the subnet:** 77 falls between 64 and 127, so it's in the **.64** subnet.
4. **Network ID:** 192.168.10.**64**. **Broadcast:** the next block minus 1 = 192.168.10.**127**.
5. **Usable hosts:** .65 – .126 (6 host bits → 2^6 − 2 = **62** hosts).

**Sizing a subnet:**
- **To fit N hosts:** pick the smallest h where 2^h − 2 ≥ N. For **50 hosts**: 2^6 − 2 = 62 works and 2^5 − 2 = 30 doesn't, so 6 host bits → **/26**.
- **To get N subnets:** pick the smallest b where 2^b ≥ N. For **6 subnets** from a /24: 2^3 = 8 works → borrow 3 bits → **/27**.

## VLSM and CIDR

- **CIDR (Classless Inter-Domain Routing):** prefixes of any length (/22, /27…) replace fixed class boundaries. CIDR also allows **route summarization (supernetting)**: advertising one route for many contiguous networks. Example: 192.168.0.0/24 through 192.168.3.0/24 (four /24s) summarize to **192.168.0.0/22**.
- **VLSM (Variable Length Subnet Masking):** using **different mask lengths inside the same network**, sizing each subnet to fit. Example: **/30** for point-to-point router links (exactly 2 usable addresses, no waste) and **/24** for user VLANs. VLSM saves address space.

## Common mix-ups

- **Usable vs total addresses:** a /26 has **64 addresses** but **62 usable**. Always subtract 2.
- **Network ID vs first usable host:** the network ID (e.g. .64) can't be assigned. The **first usable** is .65.
- **Broadcast vs last usable host:** broadcast (.127) can't be assigned. The **last usable** is .126.
- **172.16/12 boundaries:** private is **172.16 through 172.31** only.
- **APIPA vs private:** 169.254.x.x is **self-assigned link-local** (a DHCP failure), not an RFC 1918 private range.
- **Loopback:** the **whole 127.0.0.0/8** is loopback, not just 127.0.0.1.
- **Class D vs E:** D (224–239) = **multicast**; E (240–255) = **experimental**.
- **Subnets vs hosts formulas:** subnets = 2^b (no −2); hosts = 2^h − 2.

## Key terms

- **Octet:** 8 bits of an IPv4 address.
- **Network ID:** the first address of a subnet; identifies the subnet itself.
- **Broadcast address:** the last address of a subnet; reaches all its hosts.
- **Block size:** the increment between subnets in the interesting octet.
- **Route summarization:** one route covering several contiguous networks.
- **RFC 1918:** the standard defining private IPv4 ranges.
