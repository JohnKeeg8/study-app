# IPv4 addressing

An IPv4 address is **32 bits**, written as four octets (e.g. 192.168.10.25). The **subnet mask** or **CIDR prefix** says how many bits are the network portion.

## Address classes (classful)

| Class | First octet | Leading bits | Default mask | Use |
|---|---|---|---|---|
| A | 1–126 | 0 | 255.0.0.0 (/8) | Unicast, very large networks |
| B | 128–191 | 10 | 255.255.0.0 (/16) | Unicast, medium networks |
| C | 192–223 | 110 | 255.255.255.0 (/24) | Unicast, small networks |
| D | 224–239 | 1110 | – | **Multicast** |
| E | 240–255 | 1111 | – | Experimental |

127 is reserved for loopback.

## Public vs private (RFC 1918)

Private ranges aren't routed on the internet and need **NAT/PAT** to get online:
- **10.0.0.0/8** (10.0.0.0 – 10.255.255.255)
- **172.16.0.0/12** (172.16.0.0 – 172.31.255.255)
- **192.168.0.0/16** (192.168.0.0 – 192.168.255.255)

Everything else in A–C is public. Watch the edges: 172.32.x.x and 192.169.x.x are **public**.

## Special addresses

- **Loopback:** 127.0.0.0/8 (127.0.0.1). Tests the local TCP/IP stack.
- **APIPA (link-local):** 169.254.0.0/16. Windows self-assigns one when **DHCP fails**.
- **0.0.0.0:** "no address yet" (DHCP Discover source). As **0.0.0.0/0** it's the default route.
- **255.255.255.255:** limited broadcast.

## Subnetting essentials

- **Usable hosts** = 2^(host bits) − 2. The network ID and broadcast can't be assigned. Example: a /26 has 6 host bits, so 64 − 2 = **62**.
- **Block size** = 256 − the mask value in the "interesting" octet. Example: /27 has a mask octet of 224, so the block size is **32**. Subnets start at .0, .32, .64, .96…
- **Network ID** = the start of the block. **Broadcast** = the last address of the block. Usable hosts sit in between.
  - Example: 192.168.10.77/26 → block size 64 → network **.64**, broadcast **.127**, hosts .65–.126.
- **Subnets from borrowing b bits** = 2^b. Example: borrowing 3 bits from a /24 gives 8 × /27.
- **/30** gives 2 usable hosts, a classic fit for router-to-router links. /31 is also allowed on point-to-point links.

## CIDR and VLSM

- **CIDR:** classless prefixes (/27, /22) replace fixed classes and allow **route summarization**. Example: 192.168.0.0/24 through 192.168.3.0/24 summarize to **192.168.0.0/22**.
- **VLSM:** use **different mask lengths** inside one network, sized to each subnet's needs (e.g. /30 for WAN links, /24 for user VLANs). This saves addresses.

> **Exam tip:** Memorize mask octet values **128, 192, 224, 240, 248, 252, 254, 255** and powers of 2. Then practice in the **Subnetting** and **IP classes** drills until it's automatic.
