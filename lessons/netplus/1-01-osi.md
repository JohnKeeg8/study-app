# OSI model

The OSI (Open Systems Interconnection) model splits network communication into **seven layers**. Each layer has its own job and talks only to the layers directly above and below it. The exam uses it constantly: to describe devices, protocols, attacks, and to structure troubleshooting.

## The seven layers

| # | Layer | Job | PDU | Examples |
|---|---|---|---|---|
| 7 | Application | Network services for applications | Data | HTTP, DNS, SMTP, FTP, SSH |
| 6 | Presentation | Formatting, encryption, compression | Data | TLS/SSL (per CompTIA), JPEG, ASCII |
| 5 | Session | Sets up, manages, ends sessions | Data | RPC, NetBIOS session |
| 4 | Transport | End-to-end delivery, ports, reliability | Segment (TCP) / Datagram (UDP) | TCP, UDP |
| 3 | Network | Logical addressing and routing | Packet | IP, ICMP, IPsec, routers |
| 2 | Data Link | Framing, MAC addressing, local delivery | Frame | Ethernet, 802.1Q, switches, ARP |
| 1 | Physical | Bits on the medium: signals, cables, connectors | Bit | Cables, hubs, repeaters, transceivers |

> **Memory tip:** Layers 1 → 7: **P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way.

## Key ideas

- **Encapsulation:** going down the stack, each layer wraps the data from the layer above in its own header. Layer 2 also adds a trailer, the FCS used for error checking. The receiver **decapsulates** in reverse order.
- **Layer 2 sublayers:** LLC (Logical Link Control) faces Layer 3. MAC (Media Access Control) handles hardware addressing and media access.
- **Addresses by layer:** MAC address = Layer 2; IP address = Layer 3; port number = Layer 4.
- **Devices by layer:** hub/repeater = 1; switch/bridge/AP = 2; router = 3; Layer 3 switch = 2 and 3; stateful firewall = 3–4; next-gen firewall and Layer 7 load balancer = up to 7.

## TCP/IP model mapping

The 4-layer TCP/IP model groups OSI layers: **Application** (OSI 5–7), **Transport** (4), **Internet** (3), **Network Access/Link** (1–2).

## Using it to troubleshoot

- **Bottom-up:** start at Layer 1 (link lights, cables) when connectivity is completely down.
- **Top-down:** start at Layer 7 when one application fails but others work.
- If ping by IP works but a website errors, Layers 1–3 are fine and the problem is higher up.

> **Exam tip:** CompTIA places encryption (TLS) at **Layer 6**. Know which layer each device and PDU belongs to; those are the most common OSI questions.
